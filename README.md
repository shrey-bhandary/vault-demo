# BODMAS Bus Jam (React)

Interactive BODMAS learning game built entirely with React.

## Stack
- React + Vite
- CSS for UI

## Setup
1. Install Node dependencies:

```bash
npm install
```

2. Start React dev server:

```bash
npm run dev
```

3. Open:

- http://localhost:5173

## Gameplay
1. Tap operators in BODMAS order.
2. Press **Check Order**.
3. Enter the final evaluated value.
4. Earn points and grow streaks.

## Notes
- Question templates are generated client-side and include brackets, exponents, multiplication/division, and addition/subtraction.
- Division templates are generated with clean integer intermediate values for beginner-friendly practice.
